# Memory Sonoro – Prototipo

Prima versione funzionante del livello **La fattoria**.

## Contenuto
- 12 carte
- 6 coppie sonore
- grafica adatta a tablet
- conteggio mosse e coppie
- animazione finale
- suoni generati direttamente dal browser, quindi non servono file audio esterni

## Avvio
Apri `index.html` in un browser.

## Pubblicazione su GitHub Pages
1. Carica tutti i file nella cartella principale del repository.
2. Apri `Settings`.
3. Vai su `Pages`.
4. In `Build and deployment`, scegli `Deploy from a branch`.
5. Seleziona `main` e `/root`.
6. Salva.

Dopo qualche minuto GitHub mostrerà il link pubblico del gioco.
